# Stat

A large counted figure in the monospace stack (tabular numerals). Use for directory counts and headline figures. Numbers are commonly zero-padded to two digits in the app (`02`).

```jsx
<Stat label="Admins" value="02" />
<Stat label="Rows returned" value="1,284" hint="+12% vs last run" />
```

Props: `value`, `label`, `hint`, `size` (`sm`/`md`).
